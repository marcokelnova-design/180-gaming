# 180 Gaming

Mobile-first PWA prototype for the 180 Gaming concept.

This prototype demonstrates:
- Challenge Hub with Everest, Zombie Escape and Fight Night
- Everest daily mission and optional route unlock
- XP, levels, streaks and leaderboard
- PWA manifest/service worker for mobile installation
- Simulated wearable verification UI

Wearable data in this prototype is simulated. Production integration requires platform-specific health/wearable APIs and a backend verification engine.
